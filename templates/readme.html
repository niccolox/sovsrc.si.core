README

This service records content, attributes model outputs to that content, and pays rewards from a pool. The rules below come from the Pydantic models and the reward function in hello_rewards.py.

Flow: Content → Attribution → ModelOutput → calculate_rewards → RewardEvent

Ontology

Each table is one Pydantic model. The tables are generated from the model classes at request time. All models are frozen. A record does not change after creation.

License factors

Each license has a factor. The factor scales the influence of a citation. A factor of 0 gives no reward. The source_uri of a content unit points to the license text.

Reward logic

calculate_rewards(model_output, content_units, pool_amount) returns one RewardEvent. It does these steps:

  1. Read each citation in model_output.citations.
  2. Skip the citation if its content unit is not in the store.
  3. Skip the citation if the license factor is 0.
  4. Compute weight = influence_score × license_factor.
  5. Add the weight to total_weight.
  6. For each kept citation, compute amount = (weight / total_weight) × pool_amount.
  7. Write one Allocation per kept citation with share = weight.

All money values use Decimal. The allocations sum to the full pool when at least one citation is kept. If no citation is kept, the event has no allocations and the pool stays unpaid.

Worked example

Pool = 100. Two citations: c1 (sovsrc-rewards-v1, factor 1.0, influence 0.6) and c2 (cc-by-4.0, factor 0.1, influence 0.4).

weight(c1) = 0.6 × 1.0 = 0.60
weight(c2) = 0.4 × 0.1 = 0.04
total      = 0.64
amount(c1) = 0.60 / 0.64 × 100 = 93.75  → alice
amount(c2) = 0.04 / 0.64 × 100 =  6.25  → bob

Training logic

The unified demo trains a small Lightning model and pays rewards per epoch. Each training sample is a TrainingContentUnit.

  1. In each training step, write one Attribution per sample in the batch with influence_score = 1 / batch_size.
  2. At the end of the epoch, sum the influence scores per content unit.
  3. Build one ModelOutput for the epoch with those sums as citations.
  4. Call calculate_rewards with a pool of 1000.
  5. Store the RewardEvent and report earnings per contributor.
